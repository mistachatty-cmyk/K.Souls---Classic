# Test Generator

Generate tests using these steps:

1. **Analyze the code**: Read the source file to understand functions, classes, and behavior.
2. **Identify test cases**: Find edge cases, happy paths, error conditions.
3. **Check existing tests**: Look at how similar tests are structured in the project.
4. **Write tests**: Create test file following project conventions.

## Testing Guidelines

- Test happy path first
- Test edge cases and error conditions
- Use descriptive test names
- Follow existing test patterns in the project
- Include both unit and integration tests where appropriate
